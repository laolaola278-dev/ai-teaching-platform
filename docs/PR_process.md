# PR Process
- Create a feature branch: git checkout -b feature/auth-2a-2b-ci-prod-setup
- Implement changes across 2A and 2B as described here, ensuring tests pass locally
- Push branch to remote and open a PR against main (or your default branch)
- PR body should include:
- Summary of changes
- List of modified/added files
- Instructions to run tests locally
- Any known caveats or follow-up tasks
