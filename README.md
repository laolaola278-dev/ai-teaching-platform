# AI Teaching Platform

> AI 教学平台

## 项目结构

- `backend/` — 后端服务
- `frontend/` — 前端应用
- `ai-teaching-platform/` — 平台核心
- `docs/` — 文档

## 快速开始

```bash
# 后端
cd backend
pip install -r requirements.txt
python manage.py

# 前端
cd frontend
npm install
npm run dev
```
